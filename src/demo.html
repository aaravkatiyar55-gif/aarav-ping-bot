Try it in the Hack Club workspace

  1. Run /aarav-ping. The reply is Pong.
  2. Run /aarav-help for the short command list.
  3. Mention @Aarav Ping Bot in a channel where it has been invited. It replies Pong 👋 in a thread.

You need access to the Hack Club Slack workspace and its installed app to use the commands. This page describes the bot; it does not simulate a Slack conversation.

Source, setup and tests on GitHub

The bot does not save messages or execute incoming text. Slack processes the commands and mentions needed to reply. Built with Node.js and Slack Bolt, with AI assistance during development and documentation.
